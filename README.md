# DzhiggaTV

Официальные установщики и обновления DzhiggaTV для Windows.

[Скачать последнюю версию / Download the latest version](https://github.com/adrugalev/DzhiggaTV-Releases/releases/latest)

Этот репозиторий содержит только готовые выпуски и контрольные суммы SHA-256. Исходный код приложения хранится отдельно.

Версию 2.5.14 и более раннюю нужно один раз обновить вручную. Начиная с 2.5.15 плеер получает последующие обновления автоматически из этого публичного репозитория. Вход в GitHub не требуется.

This repository distributes official Windows installers, update packages and SHA-256 checksums. Application sources are maintained separately. Versions 2.5.14 and earlier require a one-time manual upgrade; version 2.5.15 and later use this public update channel without a GitHub account.
